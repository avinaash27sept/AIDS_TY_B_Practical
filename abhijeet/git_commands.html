Git Commands Reference

Master Git: Essential commands for version control mastery

Getting Started

git init

Create a new git repository in the current directory and initialize version control.

git clone

Copy an existing remote repository to your local machine with full history and branch structure.

git config --global user.name "Name"

Set your name for commits globally across all repositories. Use --global to apply to all repos.

Staging & Committing

git status

Show changed files, staged files, and current branch state. Get a complete overview of your working directory status.

git add

Stage files for the next commit. Use . to stage all changes (includes new, modified, and deleted files).

git commit -m "message"

Create a commit from staged changes with a descriptive message. Follows Conventional Commits best practices.

git commit --amend

Modify the last commit by changing its message or adding/staging more changes to the existing commit.

Branching & Merging

git branch

List local branches. Add branch-name to create a new branch at current commit.

git checkout

Switch to the specified branch. Updates working directory to match the target branch's state.

git checkout -b

Create a new branch and switch to it simultaneously. Combines branch creation and checkout in one command.

git merge

Merge specified branch into current branch. Combines changes from another branch into your current work.

git rebase

Reapply commits on top of another base tip. Linearizes history by moving current branch onto specified target.

Remote Repositories

git remote -v

Show configured remote repositories and their URLs. Displays fetch and push URLs for each remote.

git remote add origin

Add a remote named origin pointing to a URL. Configure remote repository for collaboration.

git fetch

Download objects and refs from remote without merging. Updates remote-tracking branches only.

git pull

Fetch from remote and merge into current branch. Convenience command combining fetch and merge operations.

git push

Upload local branch commits to the remote repository. Shares your changes with the team.

Inspecting & Comparing

git log

Show commit history. Use --oneline for compact display or --graph for visual branch representation.

git show

Show details of a specific commit including diff, message, author information, and file changes.

git diff

Show unstaged changes in working directory. Use git diff --staged to view staged changes for next commit.

Undoing Changes

git restore

Discard local unstaged changes to a file. Restores file from HEAD, keeping unstaged modifications removed.

git restore --staged

Unstage a file from the index while keeping working directory changes. Moves file from staging area back to working tree.

git reset --hard

Reset index and working tree to specified commit. Discards ALL changes, including staged modifications and working directory changes.

git revert

Create a new commit that undoes changes introduced by specified commit. Preserves history while reverting specific changes.

Tags

git tag

List tags. Use git tag -a v1.0 -m "msg" to create annotated tags with descriptive messages.

git push origin --tags

Push all local tags to remote repository. Shares all annotated and lightweight tags with remote team members.

Configuration & Helpers

git config --global core.editor

Set your default editor for commit messages. Configure the external editor used for crafting commit messages.

git stash

Temporarily save working directory changes to reapply later. Stashes uncommitted changes while keeping branch clean.

git stash pop

Reapply the latest stashed changes and remove them from stash list. Restores your temporary changes back to working directory.
