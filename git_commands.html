Git Commands Reference

Concise, categorized Git commands with short explanations.

```

Getting Started

git init

Create a new Git repository in the current directory.

git clone <repo>

Copy an existing remote repository to the local machine.

git config --global user.name "Name"

Set your name for commits. Use --global to apply it to all repositories.

Staging & Committing

git status

Show changed files, staged files, and the current branch state.

git add <file|.>

Stage files for the next commit. Use . to stage all changes.

git commit -m "message"

Create a commit from staged changes with a message.

git commit --amend

Modify the last commit, including its message or staged changes.

Branching & Merging

git branch

List local branches. Add a branch name to create a new branch.

git checkout <branch>

Switch to the specified branch.

git checkout -b <branch>

Create a new branch and switch to it.

git merge <branch>

Merge the specified branch into the current branch.

git rebase <base>

Reapply commits on top of another base tip to linearize history.

Remote Repositories

git remote -v

Show configured remote repositories and their URLs.

git remote add origin <url>

Add a remote named origin pointing to a URL.

git fetch

Download objects and refs from a remote without merging them.

git pull

Fetch from a remote and integrate the changes into the current branch.

git push <remote> <branch>

Upload local branch commits to the remote repository.

Inspecting & Comparing

git log

Show commit history. Use --oneline or --graph for compact views.

git show <commit>

Show details of a specific commit, including its diff, message, and metadata.

git diff

Show unstaged changes. Use git diff --staged to show staged changes.

Undoing Changes

git restore <file>

Discard local unstaged changes to a file by restoring it from HEAD.

git restore --staged <file>

Unstage a file by moving it from the index back to the working tree.

git reset --hard <commit>

Reset the index and working tree to the specified commit. This discards changes.

git revert <commit>

Create a new commit that undoes the changes introduced by the specified commit.

Tags

git tag

List tags. Use git tag -a v1.0 -m "msg" to create an annotated tag.

git push origin --tags

Push all local tags to the remote repository.

Configuration & Helpers

git config --global core.editor <editor>

Set your default editor for commit messages.

git stash

Temporarily save working directory changes to reapply later.

git stash pop

Reapply the latest stashed changes and remove them from the stash list.

For more details, run git --help or visit Git Documentation.

```
