----------------

Git Commands Reference

Concise, categorized git commands with short explanations.

Getting started

git init

Create a new git repository in the current directory.

git clone <repo>

Copy an existing remote repository to local machine.

git config --global user.name "Name"

Set your name for commits. Use --global to apply to all repos.

Staging & Committing

git status

Show changed files, staged files, and current branch state.

git add <file|.>

Stage files for the next commit. Use . to stage all changes.

git commit -m "message"

Create a commit from staged changes with a message.

git commit --amend

Modify the last commit (message or staged changes).

Branching & Merging

git branch

List local branches. Add name to create a new branch.

git checkout <branch>

Switch to the specified branch.

git checkout -b <branch>

Create a new branch and switch to it.

git merge <branch>

Merge specified branch into the current branch.

git rebase <base>

Reapply commits on top of another base tip (linearizes history).

Remote Repositories

git remote -v

Show configured remote repositories and their URLs.

git remote add origin <url>

Add a remote named origin pointing to a URL.

git fetch

Download objects and refs from remote without merging.

git pull

Fetch from remote and merge into current branch (shortcut).

git push <remote> <branch>

Upload local branch commits to the remote repository.

Inspecting & Comparing

git log

Show commit history. Use --oneline or --graph for compact views.

git show <commit>

Show details of a specific commit (diff, message, metadata).

git diff

Show unstaged changes. git diff --staged shows staged changes.

Undoing Changes

git restore <file>

Discard local unstaged changes to a file (restore from HEAD).

git restore --staged <file>

Unstage a file (move from index back to working tree).

git reset --hard <commit>

Reset index and working tree to specified commit; discards changes.

git revert <commit>

Create a new commit that undoes the changes introduced by <commit>

Tags

git tag

List tags. Use git tag -a v1.0 -m "msg" to create annotated tag.

git push origin --tags

Push all local tags to remote.

Configuration & Helpers

git config --global core.editor <editor>

Set your default editor for commit messages.

git stash

Temporarily save working directory changes to reapply later.

git stash pop

Reapply the latest stashed changes and remove them from stash list.

For more details, consult git --help or https://git-scm.com/doc
