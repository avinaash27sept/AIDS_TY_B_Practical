Git Commands Reference

Learn Git commands quickly and easily

Getting Started

git init

Create a new Git repository in the current directory.

git clone <repo>

Copy an existing remote repository to your local machine.

git config --global user.name "Name"

Set your name for commits.

git config --global user.email "email@example.com"

Set your email address for Git commits.

Staging & Committing

git status

Show changed files, staged files, and the current branch.

git add <file>

Stage a specific file for the next commit.

git add .

Stage all changes in the current directory.

git commit -m "message"

Create a commit using the staged changes.

git commit --amend

Modify the most recent commit.

Branching & Merging

git branch

List local branches.

git switch <branch>

Switch to another branch.

git switch -c <branch>

Create a new branch and switch to it.

git merge <branch>

Merge another branch into the current branch.

git rebase <base>

Reapply commits on top of another base branch.

Remote Repositories

git remote -v

Show configured remote repositories and their URLs.

git remote add origin <url>

Add a remote repository named origin.

git fetch

Download changes from a remote without merging them.

git pull

Fetch and integrate changes from a remote repository.

git push <remote> <branch>

Upload local commits to a remote repository.

Inspecting & Comparing

git log

Show commit history.

git log --oneline --graph

Show a compact graphical view of commit history.

git show <commit>

Show details and changes from a specific commit.

git diff

Show unstaged changes.

git diff --staged

Show changes that are currently staged.

Undoing Changes

git restore <file>

Discard unstaged changes to a file.

git restore --staged <file>

Unstage a file without deleting its changes.

git reset --hard <commit>

Reset the working tree and index to a specific commit. Be careful because local changes can be lost.

git revert <commit>

Create a new commit that reverses an earlier commit.

Tags

git tag

List all tags.

git tag -a v1.0 -m "Release 1.0"

Create an annotated tag.

git push origin --tags

Push all local tags to the remote repository.

Configuration & Helpers

git config --global core.editor <editor>

Set your default editor for Git.

git stash

Temporarily save uncommitted changes.

git stash pop

Reapply the latest stash and remove it from the stash list.

git clean -n

Preview untracked files that could be removed.
