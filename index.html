Why Learn Git?

Version Control

Track every change made to your project and restore previous versions anytime.

Branching

Create branches to develop new features independently without affecting the main project.

Collaboration

Multiple developers can work together efficiently using GitHub repositories.

Open Source

Contribute to thousands of open-source projects and improve your programming skills.

Common Git Commands

  • git init - Initialize a repository
  • git clone URL - Clone a repository
  • git status - Check repository status
  • git add . - Stage all files
  • git commit -m "message" - Save changes
  • git branch - View branches
  • git checkout -b branch-name - Create a new branch
  • git switch branch-name - Switch branches
  • git merge branch-name - Merge branches
  • git pull origin main - Download latest changes
  • git push origin branch-name - Upload changes

Advantages of Git

Fast

Git performs operations quickly because most actions happen locally.

Secure

Every commit is protected using SHA hashing for data integrity.

Reliable

Recover deleted work using Git history and commits.

Popular

Git is the world's most widely used version control system.
